# kts-tech-solution

> **Kryptonode Tech Solutions Pvt Ltd** — Official Corporate Portfolio & Product Engineering Platform.

---

## 🚀 Overview

Kryptonode Tech Solutions is an end-to-end engineering and product development firm delivering modern web applications, mobile platforms, enterprise cloud systems, and AI-powered solutions.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS, Framer Motion, Lucide Icons
- **Build Tool**: Vite
- **Backend / APIs**: Node.js, Vercel Serverless Functions
- **Database**: MongoDB Atlas
- **Email Delivery**: Nodemailer / SMTP Integration

## 📂 Project Structure

```
├── api/                    # Serverless API endpoints (enquiries, admin, auth)
├── src/
│   ├── components/         # Modular React components (Hero, Services, WhyKryptonode, Work, Contact, etc.)
│   ├── data/               # Portfolio static data & company configuration
│   ├── App.tsx             # Root application component
│   └── main.tsx            # Application entrypoint
├── public/                 # Static assets & icons
└── package.json            # Dependencies and scripts
```

## ⚡ Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run local development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```
